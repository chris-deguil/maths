Loi de probabilité

Loi de probabilité sur un univers fini, propriétés fondamentales et équiprobabilité.

Définition : Loi de probabilité sur un univers fini

On considère un univers fini \(\Omega = \{\omega_1\,;\,\omega_2\,;\,\ldots\,;\,\omega_n\}\).

Définir une loi de probabilité sur \(\Omega\) consiste à associer à chaque issue \(\omega_i\) un réel \(p_i = P(\{\omega_i\})\) tel que :

  • \(0 \leqslant p_i \leqslant 1\) pour tout \(i\) (chaque probabilité est un nombre entre \(0\) et \(1\)),
  • \(p_1 + p_2 + \cdots + p_n = 1\) (la somme de toutes les probabilités vaut \(1\)).

La probabilité d’un événement \(A\) est alors la somme des probabilités de ses issues : \[P(A) = \sum_{\omega_i \in A} P(\{\omega_i\})\]

Remarque :

La loi de probabilité est une hypothèse du modèle choisi : elle ne se démontre pas. Le choix du modèle peut résulter d’hypothèses d’équiprobabilité (dé équilibré, tirage au hasard) ou de fréquences observées sur de longues séries.

Propriété : Propriétés fondamentales

Soit \(P\) une loi de probabilité sur \(\Omega\). Pour tous événements \(A\) et \(B\) :

  • \(P(\varnothing) = 0\) et \(P(\Omega) = 1\),
  • \(P(\overline{A}) = 1 - P(A)\) (probabilité de l’événement contraire)
  • \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\) (formule de l’union)
  • Si \(A\) et \(B\) sont incompatibles : \(P(A \cup B) = P(A) + P(B)\).
Savoir-Faire : Compléter et utiliser une loi de probabilité — Calculer

On considère la loi de probabilité suivante sur \(\Omega = \{1\,;\,2\,;\,3\,;\,4\,;\,5\}\) :

Issue \(\omega\) 1 2 3 4 5
\(P(\{\omega\})\) \(0{,}15\) \(0{,}30\) \(a\) \(0{,}25\) \(0{,}10\)

Soit \(A\) : « le résultat est impair » et \(B\) : « le résultat est supérieur ou égal à \(3\) ».

  1. Déterminer \(a\).
Afficher la correction :

On a une expérience aléatoire dont les issues sont \(1, 2, 3, 4, 5\), donc \[P(1) + P(2) + P(3) + P(4) + P(5) = 1\] Donc \[0{,}15 + 0{,}30 + a + 0{,}25 + 0{,}10 = 1\] donc \(a = 0{,}20\).

  1. Calculer \(P(A)\) et \(P(B)\).
Afficher la correction :

\(A = \{1\,;\,3\,;\,5\}\), donc \[P(A) = P(1) + P(3) + P(5) = 0{,}15 + 0{,}20 + 0{,}10 = 0{,}45\] De même \[P(B) = 0{,}20 + 0{,}25 + 0{,}10 = 0{,}55\]

  1. Calculer \(P(A \cup B)\) en utilisant la formule de l’union.
Afficher la correction :

On a \(A \cap B = \{1\,;\,3\,;\,5\} \cap \{3\,;\,4\,;\,5\} = \{3\,;\,5\}\) Donc \[P(A \cap B) = 0{,}20 + 0{,}10 = 0{,}30\] De plus \[P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0{,}45 + 0{,}55 - 0{,}30 = 0{,}70\]

Définition : Équiprobabilité

Lorsque toutes les issues ont la même probabilité, on dit que la loi est uniforme (ou que l’on est en situation d’équiprobabilité). Dans ce cas, pour tout événement \(A\) : \[P(A) = \frac{\text{Card}(A)}{\text{Card}(\Omega)}\]

Savoir-Faire : Utiliser l’équiprobabilité — Calculer

On tire une carte au hasard dans un jeu de 32 cartes (8 valeurs \(\times\) 4 couleurs). Soit \(A\) : « la carte est un as » et \(B\) : « la carte est un cœur ».

  1. Justifier que la loi est uniforme et calculer \(P(A)\) et \(P(B)\).
Afficher la correction :

Le choix de la carte se faisant de façon aléatoire, on est en situation d’équiprobabilité.

Il y a quatre « As » dans le jeu et huit cartes « Cœur », donc \[P(A) = \dfrac{4}{32} = \dfrac{1}{8} \et P(B) = \dfrac{8}{32} = \dfrac{1}{4}\]

  1. Calculer \(P(A \cap B)\), \(P(A \cup B)\) et \(P(\overline{A})\).
Afficher la correction :

\(A \cap B\) est l’as de cœur, donc \(P(A \cap B) = \dfrac{1}{32}\).

\(P(A \cup B) = P(A) +P(B) - P(A \cap B) = \dfrac{1}{8} + \dfrac{1}{4} - \dfrac{1}{32} = \dfrac{4}{32} + \dfrac{8}{32} - \dfrac{1}{32} = \dfrac{11}{32}\).

On a \[P(\overline{A}) = 1 - P(A) = 1- \dfrac{1}{8} = \dfrac{7}{8}\]

Exercice : Dé non équilibré — Raisonner

On lance un dé à 4 faces non équilibré. La loi de probabilité est donnée par le tableau :

Face 1 2 3 4
Probabilité \(\dfrac{1}{3}\) \(\dfrac{1}{6}\) \(\dfrac{1}{4}\) \(k\)
  1. Déterminer \(k\).
Afficher la correction :

On a une expérience aléatoire dont les issues sont \(1, 2, 3, 4\), donc \[\frac{1}{3} + \frac{1}{6} + \frac{1}{4} + k = 1\] Donc \[\frac{4}{12} + \frac{2}{12} + \frac{3}{12} + k = 1\] donc \(k = 1 - \dfrac{9}{12} = \dfrac{3}{12} = \dfrac{1}{4}\).

  1. Soit \(A\) : « le résultat est pair ». Calculer \(P(A)\) et \(P(\overline{A})\).
Afficher la correction :

\(A = \{2\,;\,4\}\), donc \[P(A) = P(2) + P(4) = \frac{1}{6} + \frac{1}{4} = \frac{2}{12} + \frac{3}{12} = \frac{5}{12}\] De plus \(P(\overline{A}) = 1 - P(A) = 1-\dfrac{5}{12} = \dfrac{7}{12}\).

  1. Soit \(B\) : « le résultat est supérieur ou égal à \(3\) ». Calculer \(P(A \cup B)\).
Afficher la correction :

\(B = \{3\,;\,4\}\), donc \[P(B) = P(3) + P(4) = \frac{1}{4} + \frac{1}{4} = \frac{1}{2}\] \(A \cap B = \{4\}\), donc \(P(A \cap B) = \dfrac{1}{4}\).

De plus \[P(A \cup B) = P(A) + P(B) - P(A \cap B) = \frac{5}{12} + \frac{1}{2} - \frac{1}{4} = \frac{5}{12} + \frac{6}{12} - \frac{3}{12} = \frac{8}{12} = \frac{2}{3}\]
